# Skill catalog

Each directory contains one capability contract. These contracts are designed to be readable directly by an agent while also being exposed through Spec Kit extension commands.

The canonical names are:

- `moodle.inventory`
- `moodle.baseline`
- `moodle.compatibility`
- `moodle.plugins`
- `moodle.endpoints`
- `moodle.logs`
- `moodle.database`
- `moodle.backup`
- `moodle.upgrade`
- `moodle.validate`
- `moodle.rollback`
- `moodle.document`
